# FPS

ブラウザで遊べるBO2風FPS。オフライン（Bot戦・ゾンビ・射撃場）に加えて、部屋を作って友達とオンライン対戦できます。

## 遊び方（オンライン）

1. Renderで公開したURL（例: `https://fps-xxxx.onrender.com`）を開く
2. メニューの「オンライン」→ 名前を入れて「部屋を作る」
3. 表示された4文字の部屋コードを友達に教え、友達は「部屋コードで参加」
4. ホストがモード・マップ・制限時間・目標スコア・Botの数と強さを決めて「試合開始」

- モード: フリーフォーオール / チームデスマッチ / ドミネーション / キルコンファーム / ガンゲーム（ルールはオフラインと同じ）
- Bot: 0〜15体（合計18人まで）、強さ4段階。Botはホストのブラウザで動きます（ホストが抜けるとBotも退場）。チーム戦では人数の少ないチームに自動で入ります。
- 途中参加すると、Botが1体抜けて席を空けます。

※ オンラインは現在、メイン・サブ武器とナイフで戦います（リーサル・タクティカル・スコアストリークは未対応）。ゾンビと射撃場はオフライン専用です。

## Renderへのデプロイ

**Web Service** として作成します（Static Siteではありません）。

| 項目 | 値 |
|---|---|
| Runtime | Node |
| Region | **Singapore**（日本から最も近い。作成後は変更不可） |
| Build Command | `npm run build` |
| Start Command | `npm start` |
| Health Check Path | `/healthz` |
| Instances | **1台**（部屋はサーバーのメモリにあるため、複数台にすると同じ部屋に入れません） |

リポジトリ直下の `render.yaml` を使う場合は Blueprint からも作成できます。

### 遅延を減らすために
- **Region は Singapore** を選んでください。
- **Free プランは15分通信がないと停止**し、再起動に1分ほどかかります。対戦用には有料インスタンス（Starter以上）を推奨します。
- サーバーは依存パッケージなし（`npm install` 不要）の Node.js です。

## 通信の仕組み（低遅延のための設計）
- 自分の移動・視点は手元で即反映（サーバーの返事を待たない）
- 位置は 60Hz・1人15バイトのバイナリで送受信、TCPのNagleを無効化（即送信）
- 他プレイヤーは補間表示。補間の遅れは通信の揺れに合わせて自動で最小化（最短約17ms）
- 当たり判定は「撃った人が見ていた時刻」まで相手を巻き戻してサーバーで検証（ラグ補正）
- ダメージ上限・射線・発射位置をサーバーで確認し、明らかな不正な命中は無効

## 開発
```
src/          ゲーム本体（番号順に連結）
build.js      src → public/index.html を生成
server/       オンライン用サーバー（server.js）と武器ごとのダメージ上限（maxhit.json）
```
ローカルで動かす: `npm run build && npm start` → http://localhost:10000
